# CTFHub Writeup - 目录遍历 

## 题目类型

WEB

## 题目描述

打开题目后，打开链接，发现里面是一个标题为Index of/flag_in_here

标题下面是一个分四个文件夹的Apache的目录索引

## 解题过程

踩坑记录：1.进入页面后，我将页面里的文件一个个打开，发现都是空的

我将这几个链接输入至搜索栏，发现都显示错误：

http://challenge-a9fb2396193266c7.sandbox.ctfhub.com:10800/flag_in_here/4/4/

http://challenge-a9fb2396193266c7.sandbox.ctfhub.com:10800/flag_in_here/flag.txt

2.我决定改变策略，直接使用Python

在这一网址中https://www.online-compiler.com/compiler/pyodide输入：

import requests

base_url = "http://challenge-a9fb2396193266c7.sandbox.ctfhub.com:10800/flag_in_here"

for a in range(1,5):
    for b in range(1,5):
        target = f"{base_url}/{a}/{b}/flag.txt"
        resp = requests.get(target)
        if resp.status_code == 200:
            print("✅找到了！")
            print("路径：", target)
            print("flag：", resp.text)
            exit()
print("❌全部遍历完，没有找到")

再次报错，我又再次更换路径

新路径：在搜索栏中输入http://challenge-a9fb2396193266c7.sandbox.ctfhub.com:10800/flag_in_here/2/4/

回车，页面显示标题Index of/flag_in_here/2/2,此界面只显示一个Parent Directory文件

点击此文件，里面显示还有四个文件，点击3/文件

打开里面藏有正确的flag

##笔记

正确原因：一开始我误以为直接访问2/4/flag.txt就行，会404。

正确逻辑：必须先进/2/4/这个目录页面，页面上会显示flag.txt这个文件名，点击它，才能读取flag。

直接在地址栏拼上flag.txt去访问，会访问失败404。

这道题主要学习了：

目录索引泄露：Apache服务器配置不当，开启目录浏览功能，访问目录时直接展示目录内的文件列表。

题目设置两层嵌套数字目录，16个目录中仅有1个目录包含flag.txt，其余为空目录作为干扰。
