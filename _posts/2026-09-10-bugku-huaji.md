# BugKu CTF Writeup - 滑稽

## 题目类型

WEB

## 题目描述

签到题，点进题目链接后，满屏幕都是滑稽（斜眼笑）表情包，没有任何可点击的按钮或输入框。

## 解题过程

1. 打开题目链接，页面上铺满了滑稽表情包，乍一看什么都没有。
2. 尝试直接在页面上找输入框、按钮、链接，都没有。
3. 按 `Ctrl + U`（或在页面右键选择"查看网页源代码"）查看网页源代码。
4. 在源代码里往下翻，能看到一行 HTML 注释：

   ```html
   <!--flag{这里就是flag内容}-->
   ```

5. 把注释里的内容复制出来，提交即可。

## 笔记

这道题让我学会了：

1. 如何通过 `Ctrl + U` 或右键菜单查看网页源代码。
2. flag 经常藏在 HTML 的注释（`<!-- -->`）、隐藏标签、`<body>` 开头等位置，看源码时要整页翻一遍，不要只看页面渲染出来的内容。
3. 签到题一般都是考察最基础的信息收集
